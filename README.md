# Supermarket Sales Analysis

This project analyzes supermarket sales data and creates visual charts to compare different business metrics.

## Project files
- `assignment-July.py` - Python script for data analysis and chart generation
- `supermarket_sales.csv` - dataset used for analysis

## What the analysis includes
- Total sales by branch
- Total sales by product line
- Average spending by customer type
- Distribution of customer ratings

## Requirements
Install the following Python packages if they are not already available:

```bash
pip install pandas matplotlib
```

## How to run
From the project folder, run:

```bash
python assignment-July.py
```

## Output
The script generates chart images such as:
- `branch_total_sales.png`
- `product_line_sales.png`
- `customer_avg_spending.png`
- `customer_ratings_histogram.png`

## Notes
This analysis uses the supermarket sales dataset to explore sales performance and customer behavior.
